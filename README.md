# ChatSpace Fixed v2

This version fixes the two problems in the original demo:
- Users can create accounts and log in.
- Rooms and messages persist after refresh using browser localStorage.

## GitHub Pages
Upload `index.html`, `style.css`, `script.js`, and optionally this README to your repository.

## Important
This is still a browser-local demo. Accounts/messages are NOT shared between different phones or computers.

For a truly online chat where everyone sees the same messages, the next step is Firebase Authentication + Firestore. Firebase credentials are intentionally not included in this ZIP.
